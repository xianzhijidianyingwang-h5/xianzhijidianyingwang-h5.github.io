常见问题

把“限级”这件事说清楚

FAQ
“限像”是不是“限制级电影”站？+

不是。限像 = 限制意象 / 分级档案 / 策展语言。站里不播限制级实片，只讲分级制度与电影史。

为什么页面里有 18+ 卡片？+

用于说明“限制级”在电影分级中的含义（如港台/海外制度里未满 18 岁不得观赏），属于知识卡片，不是入口。[1,6](@ref)

能在线看《穿条纹睡衣的男孩》吗？+

不能。所有片名、导演、年级都是示例；正片请走院线、正版流媒体或电影节展映。

GitHub Pages 放这种站合规吗？+

纯分级知识 / 片单 / 影评风险低；一旦挂未授权播放器、解析接口、网盘合集，就可能被下架并涉及著作权责任。

中国大陆有电影分级吗？+

中国大陆实行电影审查与公映许可制度，不实行“普护辅限”式分级；本页分级内容主要用于电影史与国际制度科普。[9](@ref)
